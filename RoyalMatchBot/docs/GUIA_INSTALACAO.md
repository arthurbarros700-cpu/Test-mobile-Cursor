## 1. Baixar o APK

Faça o download do arquivo `RoyalMatchBot.apk` e transfira para o seu celular Android.

**Formas de transferir:**
- Enviar por WhatsApp/Telegram para si mesmo
- Copiar via cabo USB
- Usar o Google Drive ou Dropbox

---

## 2. Instalar no Celular

### Passo 2.1 — Permitir Fontes Desconhecidas

**Android 8.0 ou superior:**
1. Ao tentar instalar o APK, o Android perguntará automaticamente
2. Toque em **"Configurações"**
3. Ative **"Permitir desta fonte"**
4. Volte e instale

**Android 7.0 ou inferior:**
1. Acesse **Configurações → Segurança**
2. Ative **"Fontes desconhecidas"**
3. Instale o APK

### Passo 2.2 — Instalar o APK

1. Abra o **Gerenciador de Arquivos** do celular
2. Navegue até onde salvou o APK
3. Toque no arquivo `RoyalMatchBot.apk`
4. Toque em **"Instalar"**
5. Aguarde a instalação concluir
6. Toque em **"Concluído"** (não abra ainda)

## 3. Configurar Permissões

### 3.1 — Serviço de Acessibilidade (OBRIGATÓRIO)

Esta é a permissão mais importante. Sem ela, o bot não funciona.

**Passo a passo:**

1. Acesse **Configurações** do Android
2. Procure por **"Acessibilidade"**
   - Em alguns celulares está em: Configurações → Avançado → Acessibilidade
   - Em Samsung: Configurações → Geral → Acessibilidade
   - Em Xiaomi: Configurações → Configurações Adicionais → Acessibilidade
3. Toque em **"Serviços Instalados"** ou **"Apps Baixados"**
4. Encontre **"Royal Match Bot - Jogador Automático"**
5. Toque nele
6. Ative o interruptor
7. Na mensagem de aviso, toque em **"Permitir"** ou **"OK"**

> ⚠️ O Android exibirá um aviso dizendo que o serviço pode acessar a tela. Isso é necessário para o bot funcionar. Toque em "OK" ou "Permitir".

### 3.2 — Exibir sobre outros apps (RECOMENDADO)

1. Acesse **Configurações → Apps** (ou Aplicativos)
2. Encontre **"Royal Match Bot"**
3. Toque em **"Permissões"**
4. Encontre **"Exibir sobre outros apps"**
5. Ative a permissão

> Nota: Em alguns aparelhos esta permissão está em Configurações → Apps Especiais → Exibir sobre outros apps

### 3.3 — Ignorar Otimização de Bateria (RECOMENDADO)

Para garantir que o bot continue funcionando em background:

1. Acesse **Configurações → Bateria** (ou Gerenciamento de Energia)
2. Encontre **"Royal Match Bot"**
3. Selecione **"Sem restrições"** ou **"Não otimizar"**

## 4. Configurar o Bot

1. Abra o app **Royal Match Bot**
2. Configure a **Velocidade**:
   - **Muito Lenta**: Parece mais humano (recomendado para segurança)
   - **Normal**: Bom equilíbrio
   - **Turbo**: Mais rápido, menos natural
3. Configure a **Estratégia**:
   - **IA Avançada**: Melhor resultado geral (recomendado)
   - **Agressiva**: Para fases difíceis
4. Ative/desative **Usar Boosters** conforme preferência
5. Mantenha **Anti-Detecção** ativado

---

## 5. Iniciar e Usar

1. **Abra o Royal Match Bot** no celular
2. Confirme que os dois ícones de permissão estão ✓ (verde)
3. Toque em **"Iniciar Bot"** (botão verde)
4. **Abra o Royal Match** normalmente
5. Deixe o celular em cima da mesa
6. O bot vai jogar automaticamente!

### O bot vai:
- Navegar pelos menus automaticamente
- Iniciar fases automaticamente
- Analisar o tabuleiro e fazer as melhores jogadas
- Usar boosters quando necessário
- Coletar todas as recompensas
- Aguardar quando as vidas acabarem
- Continuar jogando quando as vidas voltarem

## 6. Solução de Problemas

### Problema: Bot não iniciou após tocar em "Iniciar Bot"
**Solução:** Verifique se o Serviço de Acessibilidade está ativo (ícone ✓ verde).

### Problema: Bot parou no meio da partida
**Solução:**
1. Verifique as configurações de bateria (desative otimização)
2. Abra novamente o Royal Match Bot e toque em Iniciar

### Problema: Bot clica no lugar errado
**Solução:**
1. Feche o app do bot
2. Abra novamente e reconfigure
3. Em celulares com resolução muito diferente de 1080x2340, pode haver imprecisão

### Problema: O bot não reconhece o Royal Match
**Solução:**
1. Verifique se o pacote do Royal Match instalado no seu aparelho é `com.ea.game.easports.kingdomofheroesroyalmatch`
2. Se for diferente (versão regional), consulte como alterar o pacote alvo

### Problema: O Royal Match foi atualizado e o bot não funciona mais
**Solução:** Aguarde uma nova versão do bot. Atualizações do jogo podem mudar a interface.

---

## Dicas de Uso

- Deixe o celular **conectado ao carregador** durante o uso prolongado
- Use **modo de alto desempenho** nas configurações de bateria
- Para **sessões longas** (noite toda), configure "Máximo de Fases por Sessão" como 0 (ilimitado)
- Acesse **Estatísticas** para ver o desempenho do bot
- Use **Logs** para entender o que o bot está fazendo
